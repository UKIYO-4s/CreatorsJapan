# README テンプレート

このテンプレートは、`案件` `企画群` `記事単位フォルダ` の `README.md` を揃えるための共通ひな形です。

```md
# 案件名または記事名

- 対象サイト:
- 状態: 準備中 / 進行中 / 確認待ち / 公開待ち / 公開済み / 保留 / アーカイブ
- 公開URL:
- 予定slug:
- post ID:
- 正本ファイル:
- 関連素材:
- 関連スクリプト:
- 担当:
- 最終更新日:

## 概要

このフォルダで何を管理しているかを 2 から 4 行で書く。

## 現在の判断

- 何が確定しているか
- 何が未確定か
- 何を見れば作業開始できるか

## フォルダ内の役割

- `リサーチ/`:
- `構成/`:
- `原稿/`:
- `素材/`:
- `公開/`:
- `保管/`:
- `scripts/`:

## 作業ルール

- 正本を更新したらここも更新する
- 一時生成物は残しっぱなしにしない
- 補助フォルダを増やしたら用途を書く

## 次アクション

- [ ] 
- [ ] 
- [ ] 

## 変更履歴

- 2026-04-07: README 作成
```

## 使い分け

- `案件 README`: 案件全体の状態、正本、公開導線を書く
- `企画群 README`: 配下記事一覧と共通リサーチを書く
- `記事 README`: その記事の原稿、公開情報、素材を特定できるようにする

## 最低限省略しない項目

- `状態`
- `正本ファイル`
- `最終更新日`
- `次アクション`
